# AI-Powered Recommendation System

## Project Overview

The AI-Powered Recommendation System is a simple recommendation engine developed in Python. The system collects user interests, compares them with predefined item attributes, and recommends the most relevant items based on similarity matching.

This project demonstrates the fundamental concepts of recommendation systems, pattern matching, and user preference analysis using basic AI logic.

---

## Features

- Accepts user interests as input
- Matches user preferences with item attributes
- Calculates similarity scores
- Ranks recommendations based on relevance
- Displays personalized recommendations
- Simple and user-friendly command-line interface

---

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Sets
- Conditional Statements
- Loops

---

## How It Works

1. The user enters their interests.
2. The system compares those interests with available item tags.
3. A similarity score is calculated based on matching interests.
4. Items are ranked according to their similarity scores.
5. The most relevant recommendations are displayed.
